# HiCodex v0.3.3-beta.1 — Experimental account switching

This is an opt-in **prerelease** for Windows x64. **v0.3.2 remains the latest stable release.** Real-account desktop acceptance testing is still in progress; this release is not a claim of stable multi-account support.

这是 Windows x64 **实验性预发布版**，供主动试用；**稳定版仍为 v0.3.2**。真实账号的桌面验收尚未完成，请勿视为稳定的多账号支持。

## What's new / 更新内容

- Native optional account management, independent of codex-auth and Node.js.
- Save the current ChatGPT login, import Codex-generated `auth.json`, or import registered codex-auth accounts and aliases without changing the source files or active login.
- Account snapshots and the last-switch recovery backup are encrypted for the current Windows user using DPAPI.
- Switch saved accounts and manually reopen Codex; restore the credentials from before the last switch when safe to do so.
- Identities are hidden by default. The selected account is checked and disabled. Success feedback disappears after about eight seconds; switch/restore have one confirmation and errors remain explicit.
- Refresh coordination prevents stale quota results from reappearing after switching. Existing single-account quota viewing requires no account setup.
- Quota bucket selection and taskbar centering ownership checks are improved; transient usage fetch failures are retried.

- 原生可选账号管理，不依赖 codex-auth 或 Node.js。
- 保存当前 ChatGPT 登录、导入 Codex 生成的 `auth.json`，或导入 codex-auth 已登记账号及别名；不修改来源文件或当前登录。
- 账号快照及最近一次恢复备份使用 Windows DPAPI 加密。
- 支持选择已保存账号并手动重启 Codex，以及在安全条件下恢复上次切换前的凭据。
- 默认隐藏身份；当前账号带勾且不可重复选择。成功提示约 8 秒后消失；切换和恢复各保留一次确认，错误会明确提示。
- 协调账号操作与额度刷新，避免切换后重新显示旧额度；单账号用户无需配置账号库。
- 改善额度桶选择与任务栏居中恢复检查，对临时额度读取失败进行重试。

## Use safely / 使用注意

Exit the old HiCodex, then download and run `HiCodex.exe` (or extract the ZIP). No installation is required. **Close Codex, CLI/IDE sessions and other account switchers before confirming a switch or restore; reopen Codex afterward.** Importing accounts alone does not change your login.

退出旧 HiCodex 后，下载并运行 `HiCodex.exe`，或解压 ZIP 后运行，无需安装。**确认切换或恢复前，请关闭 Codex、相关 CLI/IDE 会话和其他账号切换工具，完成后手动重启 Codex。**仅导入账号不会改变当前登录。

Only Windows-native ChatGPT file credentials are supported. API keys, WSL and explicit keyring/auto/ephemeral storage are unsupported. The tool does not edit local conversation files, but cross-account continuation and account-specific permissions still need real-world verification. Imports are snapshots, not continuous synchronization; avoid alternating managers with stale snapshots.

仅支持 Windows 原生 ChatGPT 文件凭据；不支持 API Key、WSL 或显式 keyring/auto/ephemeral 存储。工具不修改本地对话文件，但跨账号接续及账号权限仍需真实验证。导入是快照复制，不会持续同步，请避免多个管理器交替使用旧凭据。

`auth.json` and interrupted-write recovery/staging files may contain plaintext credentials. Never upload them, your account store, tokens or cookies in feedback. DPAPI does not protect against malicious software running as the same Windows user. External writers and power failures cannot be completely excluded. The executable is unsigned; Windows may show a SmartScreen warning.

`auth.json` 和异常中断遗留的恢复/临时文件可能含明文凭据。反馈时不要上传这些文件、账号库、令牌或 Cookie。DPAPI 不能防御以同一 Windows 用户运行的恶意程序；也无法完全排除外部并发写入与断电风险。EXE 尚未签名，Windows 可能显示 SmartScreen 提示。

## Validation and rollback / 验证与回退

Automated Windows tests use synthetic credentials and isolated temporary directories. Real-account acceptance must cover repeated switch/restart, correct quotas, existing conversation continuation, single-account use, codex-auth coexistence and failed import/restore behavior before a stable release. See [the acceptance checklist](https://github.com/fangzh5/hi-codex/blob/codex/experimental-account-switching/docs/experimental-accounts.md).

自动化 Windows 测试使用模拟凭据和隔离临时目录。转为稳定版前，仍需验证反复切换重启、额度对应、原对话接续、单账号使用、codex-auth 共存及导入/恢复失败场景。

To roll back the application, exit this version and run v0.3.2. Reverting the application does **not** automatically restore a previously selected account. If needed, select the desired saved account (or use the last-switch restore while it is still applicable) before reverting. Do not delete credential files to roll back.

程序回退：退出实验版，运行 v0.3.2。回退程序**不会自动切回原账号**；如需切回，请先选择所需账号，或在仍满足条件时使用最近一次切换恢复。不要通过删除凭据文件来回退。
