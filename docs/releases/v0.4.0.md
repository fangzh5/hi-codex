# HiCodex v0.4.0

Native optional account management joins the main release, together with taskbar recovery and resizing fixes. Single-account usage viewing needs no account setup.

原生可选账号管理并入正式版，同时改进任务栏恢复与尺寸变化处理。单账号用户无需配置账号库，原有额度查看方式不变。

## Changes / 更新

- Save ChatGPT accounts, import Codex-generated auth JSON or registered codex-auth snapshots, select accounts and restore the last-switch credentials. No codex-auth/Node.js runtime dependency.
- User-scoped DPAPI account storage, hidden identities by default, current-account selection protection and brief non-modal success feedback.
- Credential write checks and recovery backups; imported files and codex-auth source data remain unchanged. Switching still requires closing Codex and other switchers, then manually reopening Codex.
- Correct Codex quota-bucket selection and retry transient usage-read failures.
- Bound centered icons to the parent client area; restore when space is insufficient and handle display/DPI changes with the existing low-frequency timer.
- Preserve failed taskbar-style restores for retry, discard stale owner records and skip rewriting unchanged styles. No additional thread, timer or dependency for taskbar fixes.
- Ignore local credentials, account stores, recovery files and secret environment files in Git.

- 支持保存 ChatGPT 账号、导入 Codex auth JSON 或 codex-auth 已登记快照、选择账号及恢复上次切换前凭据；不依赖 codex-auth 或 Node.js。
- 账号库采用当前 Windows 用户范围 DPAPI 加密，默认隐藏身份，防止重复选择当前账号，成功后使用短暂提示。
- 增加凭据替换校验及备份恢复；导入不修改来源文件。切换前关闭 Codex 和其他切换工具，完成后手动重启 Codex。
- 改善额度桶选择，临时读取失败自动重试。
- 居中位置限制在父窗口可见区域，空间不足时恢复；通过现有低频定时器处理分辨率及 DPI 变化。
- 任务栏样式恢复失败可重试，清理失效记录，样式不变时不重复设置；任务栏修复没有增加线程、定时器或依赖。
- Git 忽略本地凭据、账号库、恢复文件和私密环境配置。

## Limits and safety / 限制与安全

Only Windows-native ChatGPT file credentials are supported; API keys, WSL and explicit keyring/auto/ephemeral modes are unsupported. Account imports are snapshots, not continuous synchronization. Do not alternate switchers using stale snapshots. Auth files and interrupted-write leftovers can contain plaintext secrets; do not share them. DPAPI cannot protect against malicious software running as the same Windows user.

仅支持 Windows 原生 ChatGPT 文件凭据；不支持 API Key、WSL 或显式 keyring/auto/ephemeral 存储。导入是快照复制，不会持续同步，请避免多个切换器交替使用旧快照。auth 文件与异常中断遗留文件可能包含明文凭据，不要分享。DPAPI 无法防御以同一 Windows 用户运行的恶意程序。

The tool does not edit local conversation files, but cross-account continuation, enterprise restrictions and real RDP sessions are not fully validated. Taskbar icon centering remains primary-screen only. Secondary-screen acrylic is not guaranteed. If Windows refuses to read the original accent policy, transparency is skipped to protect the system style. This is a known compatibility limit, not a verified fix for every Windows build. Forced termination cannot run style cleanup. The executable remains unsigned.

工具不修改本地对话文件，但跨账号接续、企业策略及真实 RDP 场景尚未完整验收。图标居中仍仅支持主屏；副屏毛玻璃不保证生效。Windows 拒绝读取原样式时，会跳过透明设置以保护系统样式；这是已知兼容性限制，并非宣称所有 Windows 版本均已修复。强制结束进程无法执行样式恢复。EXE 仍未签名。

## Verification and upgrade / 验证与升级

37 automated tests cover synthetic account credentials, file replacement/recovery, quota parsing, visibility, centering boundaries and accent restore ownership. Format, Clippy and release build are checked. Automated geometry checks are not a substitute for real RDP or long-duration resource testing. See [taskbar validation](https://github.com/fangzh5/hi-codex/blob/main/docs/taskbar-validation.md).

37 项自动化测试覆盖模拟账号、文件替换恢复、额度解析、隐私显示、居中边界及样式恢复归属检查；同时检查格式、Clippy 和发布构建。几何测试不替代真实 RDP 或长期资源占用测试。

Exit old HiCodex, download `HiCodex.exe` (or extract the ZIP), and run it. Existing beta account stores remain in place. Downgrading the application does not restore the previously selected account; select the desired account before downgrading if needed. Never delete auth files as a rollback method.

退出旧 HiCodex，下载并运行 `HiCodex.exe`，或解压 ZIP 后运行。现有 beta 账号库继续保留。程序降级不会切回旧账号，如需切回请先选择所需账号，不要通过删除凭据来回退。
