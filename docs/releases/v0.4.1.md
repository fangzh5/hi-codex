# HiCodex v0.4.1

Fix taskbar centering flashes during notification-icon changes and improve account saving after a desktop sign-out/sign-in.

修复托盘图标增删时的居中闪烁，并改进桌面端登出、换账号后的保存流程。

## Changes / 更新

- Reserve leading space in the native Windows task-band container. Explorer can reset the inner icon list to its normal origin while the container keeps the centering space. Existing layout events and the two-second recovery check update the reservation without permanent fast polling.
- Preserve recent icon measurements during temporary accessibility failures; respect native child minimum widths and right-side controls. Disabling centering or normal exit restores only HiCodex's own native header change. Reentrant cleanup no longer waits on an active native-control call.
- Wait briefly for a new login file to finish writing. If no file credentials are available, offer managed browser authorization instead of a generic `missing` error.
- Add **Accounts → Sign in and save account...**. Choose the account to save in your browser; authorization uses a private temporary home and stores an encrypted snapshot without changing the desktop login or other saved accounts. Cancellation is checked again after authorization and before the library write; pending authorization times out after three minutes.
- Allow selecting a saved account after sign-out removed `auth.json`, without exposing a stale restore backup. Concurrently created credentials are not replaced.
- Add a credential-free, read-only layout diagnostic: `HiCodex.exe --taskbar-diagnose`.

- 使用 Windows 原生任务栏容器预留左侧留白；Explorer 将内部图标列表归零时，父容器仍保留居中空间。原有布局事件和两秒恢复检查继续更新留白，没有常驻快速轮询。
- 短暂读不到图标时保留有效尺寸；遵守最小子区域宽度及右侧控件边界。关闭居中或正常退出时，只恢复 HiCodex 自己修改的原生留白，并避免恢复过程中的消息重入等待。
- 保存账号时短暂等待新登录文件写入；没有文件凭据时，提供浏览器授权入口，替代笼统的 `missing` 错误。
- 新增 **Accounts → Sign in and save account...**。请在浏览器选择要保存的账号；授权在私有临时目录完成，加密存入账号库，保留桌面登录及其他已存账号。授权完成后和写入前再次检查取消请求；等待授权三分钟后超时。
- 登出删除 `auth.json` 后仍可选择已存账号；清理不属于本次切换的旧恢复备份，且不会覆盖并发创建的新登录。
- 新增不读取账户凭据的只读任务栏布局诊断入口。

## Upgrade / 升级

Exit the running HiCodex, replace it with `HiCodex.exe` from this release (or extract the ZIP), then run it. Existing settings and the DPAPI account library are retained. To switch a saved account, close Codex and other switchers first, select the account in HiCodex, then reopen Codex manually.

先退出正在运行的 HiCodex，再下载并运行本版 `HiCodex.exe`，或解压 ZIP 后运行。原有设置和 DPAPI 账号库继续保留。选择已存账号切换时，仍需先关闭 Codex 和其他切换工具，再选择目标账号并手动重开 Codex。

## Verification and limits / 验证与限制

53 automated tests cover account snapshots, cancellation, file replacement/recovery, quota parsing and native taskbar layout. A separate hidden native-control process reproduces the previous list-reset problem and checks 50 reset/width-change cycles without corrective callbacks. Other tests cover newer external headers, timeout buffer lifetime and reentrant cleanup. Windows CI gates the release on formatting, Clippy, tests and an MSVC release build. The local taskbar trial was reported stable by the user; this does not certify every Windows build, real RDP, multiple displays or long-duration behavior.

53 项自动化测试覆盖账号快照、取消、文件替换恢复、额度解析和原生任务栏布局。独立隐藏控件进程先复现原来的列表归零问题，再验证 50 次归零与宽度变化；断言前不运行位置校正。另有测试覆盖外部新留白、超时缓冲区和消息重入清理。正式包须通过 Windows CI 的格式、Clippy、测试及 MSVC 发布构建。本机试用获用户反馈稳定，但不代表所有 Windows 版本、真实 RDP、多显示器及长期运行均已验收。

Only Windows-native ChatGPT file credentials are supported. Direct export of desktop-only in-memory credentials, keyring/auto/ephemeral storage, API-key accounts and WSL switching remain unsupported; browser authorization is the fallback when no file login can be saved. Sign-out or token revocation can invalidate older snapshots. Auth files and interrupted temporary directories can contain plaintext credentials. The executable is unsigned. See [account behavior](https://github.com/fangzh5/hi-codex/blob/main/docs/experimental-accounts.md) and [taskbar validation](https://github.com/fangzh5/hi-codex/blob/main/docs/taskbar-validation.md).

仅支持 Windows 原生 ChatGPT 文件凭据；不直接导出桌面端内存凭据，不支持 keyring/auto/ephemeral、API Key 或 WSL 切换。缺少可保存的文件登录时可使用浏览器授权。登出或令牌撤销可能让旧快照失效；auth 文件和异常中断的临时目录可能含明文凭据。EXE 仍未签名。
